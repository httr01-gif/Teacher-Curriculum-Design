교과형 개별화교육계획 실천 도구

개념 기반 교육과정 재구성 프롬프트 생성기

국가교육위원회 고시 제2026-2호 일부개정을 반영한 성취기준 691개와 일상생활 활동 75개를 담았습니다. 핵심 아이디어와 내용 요소는 고시 문서에서 자동으로 채워집니다. 학년군과 교과를 고르고 성취기준을 선택한 뒤 학생별 개별화교육계획 목표를 넣으면 교사 교육과정 재구성안을 요청하는 프롬프트가 만들어집니다.

Step 01

수업 기본 설정

사용 목적을 고르고, 학년군과 교과를 고르면 해당 성취기준이 목록에 나타납니다. * 표시는 교사가 반드시 입력하는 항목입니다.

Step 02

개념적 토대

고시 문서에서 불러온 내용을 확인하고 일반화 문장만 직접 씁니다. * 표시는 교사가 반드시 입력하는 항목입니다.

내용 요소

문장 틀
개념 넣기

안내 질문 선택 입력 · 비워 두면 AI가 작성합니다

Step 03

학생별 개별화교육계획 목표

학생을 여러 명 등록하면 하나의 활동에 서로 다른 목표를 배치합니다. * 표시는 교사가 반드시 입력하는 항목입니다.

개인정보 안내 · 학생 실명 대신 학생A, 학생B 같은 코드를 사용하세요. 진단명과 개인 식별 정보는 입력하지 않습니다. 입력 내용은 이 브라우저에 자동 저장되므로 공용 컴퓨터에서는 작업 후 위쪽의 새로 작성을 눌러 지우세요.

체험용 예시 학생 1단계에서 고른 교과에 맞는 수준별 예시 목표를 불러옵니다. 실제 수업에서는 학생의 IEP 목표로 바꾸어 쓰세요.

Step 04

수업 설계 조건

자료 유형과 평가 계획, 일반화 연계 범위를 정합니다.

Step 05

생성된 프롬프트

프롬프트를 복사해 Claude 같은 생성형 AI의 새 대화창에 붙여 넣으세요. 결과를 받은 뒤 아래 점검표로 현장 적합성을 확인합니다.
