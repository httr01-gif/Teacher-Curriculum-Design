# 교과형 IEP 개념 기반 재구성 프롬프트 생성기

2022 개정 특수교육 기본 교육과정(국가교육위원회 고시 제2026-2호 일부개정 반영)을 내장한 프롬프트 생성기입니다.
API 연결 없이 프롬프트만 만들며, 교사가 생성형 AI 대화창에 붙여 넣어 사용합니다.

## 내장 자료

| 자료 | 규모 |
|---|---|
| 성취기준 | 691개 |
| 일상생활 활동 | 75개 |
| 핵심 아이디어 | 47개 영역, 112문장 |
| 내용 요소 | 140개 교과 영역 학년군 조합, 1,484개 항목 |
| 체험용 예시 IEP 목표 | 17개 교과, 상 중 하 수준 |

## 배포

`index.html` 파일 하나를 GitHub Pages에 올리면 됩니다. 서버나 API 키가 필요 없습니다.

## 사용 목적

| 모드 | 용도 | 결과 |
|---|---|---|
| 단원 수업 준비 (기본) | 평상시 단원 수업 준비 | 단원 개념 요약, 차시 흐름표, 학생별 IEP 연계 지원방안표 |
| 학기 지도계획 | 학기별 지도계획 제출 | 교사 교육과정 재구성안 표 일곱 개 |

## 교사가 반드시 입력하는 항목

| 단계 | 항목 |
|---|---|
| 1단계 | 단원명 |
| 2단계 | 일반화 문장 (문장 틀과 개념 넣기 도움 제공) |
| 3단계 | IEP 목표 한 명 이상 (체험용 예시로 대체 가능) |

## 입력 유지

| 기능 | 동작 |
|---|---|
| 단계 이동 | 이전 버튼, 단계 표시줄, 브라우저 뒤로 가기 모두 입력 유지 |
| 자동 저장 | 이 브라우저에 저장, 새로고침 후에도 복원 |
| 새로 작성 | 저장된 입력을 모두 지움. 공용 컴퓨터에서는 작업 후 반드시 실행 |

## 개인정보

- 학생 실명 대신 학생 코드를 사용합니다
- 진단명, 생년월일, 주소, 보호자 정보는 입력하지 않습니다
- 프롬프트를 붙여 넣는 순간 IEP 목표가 해당 AI 서비스로 전송됩니다. 연구학교 생성형 AI 활용 가이드라인 범위 안에서 사용합니다

## 갱신

성취기준은 `CURRICULUM`, 핵심 아이디어는 `BIGIDEA`, 내용 요소는 `CONTENT`, 예시 목표는 `SAMPLE_GOALS` 객체를 교체합니다.
